Quick Start Guide (2 minutes)

        

        

          

            
1

            
Select a Topic

            
Choose from 47 pre-configured ACS topics in the left sidebar. Each topic is aligned with ESC Guidelines questions.

            

              
            

          

          

            
2

            
Load Evidence

            
Click "Update from ClinicalTrials.gov" to automatically fetch RCT data, or import from R datasets.

            
    
              
  • Auto-extracts study arms, outcomes, and sample sizes
    • 
              
  • Deduplicates against existing data
    • 
              
  • Works offline after first load
    • 
            

          

          

            
3

            
Review Analysis Tabs

            
Navigate through the analysis tabs to explore your evidence:

            
    
              
  • Overview - Evidence snapshot and warnings
    • 
              
  • Pairwise Meta - Forest plot with click-to-exclude
    • 
              
  • Network - NMA with treatment rankings
    • 
              
  • GRADE - Automated certainty assessment
    • 
            

          

          

            
4

            
Export Results

            
Generate publication-ready outputs for your guideline panel:

            
    
              
  • PDF Report - Complete analysis summary
    • 
              
  • R Script - Reproducible code for verification
    • 
              
  • CSV/JSON - Data for further analysis
